# AIRDROPX — REAL MULTIPAGE GITHUB PAGES

Upload the CONTENTS of this folder to the repository root on the `main` branch.

GitHub Pages:
Settings → Pages → Deploy from a branch → main → /(root)

This package contains real directory/index.html pages for the major routes,
so links such as /airdrops/, /earn/, /wallet/, etc. are served by GitHub Pages
without requiring a server rewrite.

Dynamic campaign URLs are still handled by the included 404.html fallback.
